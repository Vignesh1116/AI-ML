#### Pandas - Work with numerical arrays

| Task              | Pandas                 |
| ----------------- | ---------------------- |
| Read CSV          | `pd.read_csv()`        |
| Save CSV          | `df.to_csv()`          |
| First rows        | `df.head()`            |
| Last rows         | `df.tail()`            |
| Shape             | `df.shape`             |
| Data types        | `df.dtypes`            |
| Statistics        | `df.describe()`        |
| Missing values    | `df.isnull().sum()`    |
| Fill missing      | `df.fillna()`          |
| Remove missing    | `df.dropna()`          |
| Duplicates        | `df.duplicated()`      |
| Remove duplicates | `df.drop_duplicates()` |
| Sort              | `df.sort_values()`     |
| Group             | `df.groupby()`         |
| Count values      | `df.value_counts()`    |
| Mean              | `df.mean()`            |
| Maximum           | `df.max()`             |
| Minimum           | `df.min()`             |
